## Current operational design (subject to real broker verification)

| Cadence or boundary | Current source behavior |
|---|---|
| About **5 seconds** | Observe broker account, outstanding pending order or known filled position, durable coordinator and watchdog |
| Newly completed **M15** | Check seven timeframe market context and experimental TPB; call OpenAI only for a qualifying setup; broker risk/execution governs orders |
| **AI API** | Real user's allowed models `gpt-5.6-luna/terra/sol`, `gpt-5.6-luna` tested and pinned; USD budget **$2 per UTC day default**, caching; **no fixed 32-reviews/day** |
| **Existing order limit** | Source currently limits **new order submissions to three per UTC day**, one known exposure, max 0.01 lot initial. This is separate from model-request budgeting, and may be prospectively revised with verified risk tests |
| **Unfilled pending order** | Candidate STOP expires about **45 minutes** after its signal bar; this **does not** restrict daily hours of entry eligibility |
| **Open known position** | Broker-side initial SL/TP, durable break-even/trailing SL and conditional AI HOLD/early exit/inward TP refinement; actual broker modification receipts still needed |
| **Ops and research** | Hidden task, compact health and rotated cycle logs, durable local SQLite; broker outcome/daily chronology; no unvalidated automatic strategy promotion |
