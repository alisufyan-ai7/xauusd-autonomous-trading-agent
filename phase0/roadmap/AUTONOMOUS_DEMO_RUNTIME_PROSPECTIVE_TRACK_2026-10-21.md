## What is implemented

- Pure deterministic `src/xauusd_agent/features/autonomous_demo_advisory.py` uses broker-neutral, *fully completed* and time-ordered H1/M15 XAUUSD bars to propose LONG/SHORT, reference entry, stop and 1.5R/2R targets. No screenshot or human direction needed for this advisory. It uses a simple H1 EMA20/EMA50 trend and M15 12-closed-bar breakout *hypothesis*. Experimental baseline only; expectancy and costs are UNPROVEN.
- Fail-closed on incomplete/future/stale data, missing history, wrong symbol/timeframes, gaps, broad price divergence, invalid stop/tick grid, weak trigger/ambiguous trend. Identical observed inputs give same signal ID; all NO_TRADE results have no entry/stop. Advisory explicitly sets `execution_permitted=False` and contains **no** MT5, order, login, network, position or broker import. `pytest` synthetic tests were first reproduced in a disposable Python3.13 local approximation of project Bar/Timeframe model; GitHub CI/native Python3.12 exact branch testing must still independently complete.
