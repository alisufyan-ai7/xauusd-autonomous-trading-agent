# Security and Redaction Policy

Do not commit credentials, MT5 login numbers, passwords, API keys, identity documents, residential addresses, unredacted statements, raw account captures, or support conversations containing personal data.

Before committing an evidence-derived record:

1. redact direct identifiers and secrets;
2. preserve provenance and SHA-256 separately;
3. inspect archive paths and file types;
4. classify the record;
5. confirm the repository copy is metadata/review material, not the protected source evidence.
